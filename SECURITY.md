# Security Policy

## Supported Versions

Only the latest published version of **RushEvaluator** receives security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential exploit in RushEvaluator, please do **NOT** open a public issue.

Instead, please send an email directly to the project maintainer:
- **Maintainer:** Rushikesh Surve
- **Email:** `rushikeshsurve193@gmail.com`

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- The version of RushEvaluator and Java environment tested.

You will receive an initial response within 48 hours. Validated vulnerabilities will be addressed promptly in a patch release.
